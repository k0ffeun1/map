# Универсальный генератор сухопутных клеток v2

## Что реализовано

Новый генератор больше не содержит координат или специальных линий, подобранных только для Ла-Коруньи.

Одна и та же логика применяется ко всем провинциям:

```text
финальный полигон провинции
→ региональный target_cell_area_km2
→ нужное число клеток
→ городская ветка с защитной зоной
→ поиск узких мест по medial axis
→ несколько кандидатов на каждый разрез
→ последовательное рекурсивное деление
→ общая polygonize/coverage_simplify
→ валидация
```

## Главное отличие от прежнего варианта

Прежняя реализация выбирала одну пару центров и строила геодезическую границу. Это часто давало неудачные клетки и слишком близкую к городу границу.

В v2 для каждого разреза оценивается несколько вариантов:

- подтверждённый перешеек по медиальному скелету;
- weighted farthest pair;
- основная ось формы провинции;
- вторичная ось;
- два крупных повёрнутых варианта.

Выбирается не первый вариант, а кандидат с лучшей суммарной оценкой:

```text
баланс площади
+ компактность обеих частей
+ длина общей границы
+ минимальная толщина
+ бонус реальному перешейку
+ жёсткая защита города
```

## City-first без овального пузыря

Городская клетка не вырезается кругом или буфером.

Вместо этого город остаётся в защищённой ветке каждого раннего бинарного разреза. Ветка делится первой до тех пор, пока не становится одной финальной клеткой.

Дополнительно все пиксели в защитном радиусе города принудительно остаются на городской стороне внутренней границы. Внешняя граница провинции и берег при этом не считаются нарушением.

## Полуострова и перешейки

Используется `medial_axis` и карта расстояний до внешней границы.

В узком месте скелета проверяется, разделяет ли локальный разрез провинцию на две значимые части. Микроскопический хвост не считается самостоятельной лопастью.

Если подтверждённый перешеек найден, он получает бонус, но не побеждает автоматически: очень плохая по форме нарезка может быть отклонена в пользу другого кандидата.

## Последовательная генерация

Генератор не строит одну многосеменную Voronoi-сеть.

Каждый разрез делит только одну текущую часть:

```text
провинция
→ 2 части
→ одна из частей делится ещё раз
→ повторять до N клеток
```

Поэтому не возникает обязательной центральной звезды из нескольких границ.

## Исправление городов у побережья

Часть точек городского датасета может находиться на несколько пикселей за итоговым полигоном из-за несовпадения береговых и административных данных.

Теперь такая точка:

1. не заменяется сразу центром провинции;
2. проецируется на ближайшее место полигона;
3. слегка сдвигается внутрь;
4. сохраняет исходную координату в `original_pos`;
5. получает `source = province_city_dataset_snapped_inside`.

## Запуск одной провинции

```bash
python scripts/tools/build_land_cells_universal_v2.py \
  --province "La Coruña" \
  --grid-size 320 \
  --output assets/land_cells_lacoruna_v2.json \
  --debug-dir reports/lacoruna_v2
```

## Запуск всех провинций с настроенными регионами

```bash
python scripts/tools/build_land_cells_universal_v2.py \
  --all-configured \
  --grid-size 256 \
  --output assets/land_cells_universal_v2_iberia_all.json \
  --no-debug-images
```

Полный последовательный прогон может быть долгим. Для разработки разумно разделять список провинций на несколько процессов, а затем объединять результаты.

## Что ещё не является окончательным

Этот генератор использует:

- форму провинции;
- город;
- узкие места;
- медиальный скелет;
- региональную площадь клетки.

В переданном bundle нет полноценной карты:

- водоразделов;
- высот и склонов;
- крупных рек как барьеров;
- исторических дорог;
- долин и горных проходов.

Поэтому v2 уже универсален и топологически устойчив, но пока создаёт **естественные границы по форме провинции**, а не полноценные физико-географические границы.

Следующий качественный шаг:

```text
добавить в cost field:
- DEM/slope;
- ridges/watersheds;
- major rivers;
- valley corridors;
```

Без этих данных нельзя честно ожидать, что автоматический алгоритм сам угадает реальную долину или горный хребет по одному внешнему контуру провинции.
