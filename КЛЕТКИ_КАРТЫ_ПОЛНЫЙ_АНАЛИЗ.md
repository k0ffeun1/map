# Клетки карты: полный дизайн-анализ

## 0. Главная идея

Клетка карты — это минимальная физическая единица мира. Она не должна быть просто “лес”, “гора” или “равнина”. В хорошей глобальной стратегии клетка должна состоять из нескольких слоёв:

```text
Клетка = природа + освоение + инфраструктура + состояние
```

Разделение нужно для того, чтобы одна и та же земля могла играть по-разному в зависимости от природных условий, решений игрока, технологий, населения, войны и экономики.

Например, клетка может быть такой:

```text
Поверхность: суша
Рельеф: холмы
Природный покров: средиземноморский кустарник
Почва: каменистая
Климат: средиземноморский
Влажность: сухая
Особенности: рядом побережье
Природный ресурс: нет
Освоение: оливковые рощи
Инфраструктура: просёлочная дорога
Состояние: нормальное
```

Такая клетка не “оливки по природе”. По природе это сухие каменистые холмы с кустарником. **Оливковые рощи** — это уже результат человеческого освоения.

Главное правило:

```text
Природа клетки отвечает: что здесь возможно.
Освоение отвечает: что люди сделали с этой землёй.
Инфраструктура отвечает: насколько хорошо клетка связана и обслуживается.
Город отвечает: во что сырьё превращается.
```

## 1. Почему нельзя делать клетку одним типом

Плохая модель:

```text
Клетка = лес
Клетка = гора
Клетка = море
Клетка = пашня
Клетка = виноградники
```

Проблема в том, что тут смешиваются разные вещи:

- гора — это рельеф;
- лес — это природный покров;
- море — это поверхность;
- пашня — это человеческое освоение;
- виноградники — это тоже человеческое освоение;
- рыба — это ресурс;
- порт — это инфраструктура/городской объект;
- виноделие — это переработка в городе.

Правильная модель:

```text
Клетка имеет несколько параметров:
- поверхность;
- рельеф;
- природный покров;
- почву;
- климат;
- влажность;
- природные особенности;
- природные ресурсы;
- освоение;
- инфраструктуру;
- временные состояния.
```

Так одна клетка может быть:

```text
Суша + холмы + лес + влажный климат + обычная почва
```

А другая:

```text
Суша + холмы + маквис + средиземноморский климат + каменистая почва
```

Обе клетки — холмы, но первая лучше для леса/пастбищ, вторая — для оливок/винограда.

## 2. Базовая структура клетки

Минимальная структура:

```text
Cell {
  id
  x, y

  surface_type          // суша, море, озеро
  relief_type           // равнина, холмы, горы и т.д.
  natural_cover_type    // лес, луга, степь, кустарник и т.д.
  soil_type             // плодородная, обычная, бедная, каменистая и т.д.
  climate_type          // океанический, средиземноморский, сухой и т.д.
  moisture_type         // сухая, нормальная, влажная и т.д.

  natural_features      // река, гавань, побережье, перевал и т.д.
  natural_resource      // железо, соль, рыба, лес, камень и т.д.

  development_type      // пашня, пастбища, виноградники и т.д.
  development_level     // уровень освоения 0–5
  maturity              // зрелость освоения 0–100
  damage                // повреждение/разорение 0–100

  infrastructure_flags  // дорога, мост, ирригация, маяк и т.д.
  state_flags           // засуха, паводок, война, пожар и т.д.

  owner_id
  city_id
  region_id             // пока вопрос регионов можно оставить открытым
}
```

В MVP можно упростить:

```text
Cell {
  surface
  relief
  cover
  soil
  climate
  moisture
  features
  resource
  development
  level
  maturity
  damage
  city_id
}
```

## 3. Поверхность клетки

Поверхность отвечает на вопрос:

```text
Это суша, вода или особая водная зона?
```

Базовые типы:

```text
land    // суша
sea     // море/океан
lake    // озеро
```

Реки лучше не делать обычными клетками. Их лучше делать отдельными линиями/объектами, проходящими через клетки или между клетками.

Крупные реки могут иметь отдельные речные сегменты:

```text
RiverSegment {
  river_id
  from_cell
  to_cell
  navigable_level
  crossing_difficulty
  floodplain_cells
}
```

### Эффекты поверхности

Суша:

```text
+ сухопутное движение
+ земледелие/пастбища/лес/рудники
+ города/дороги/крепости
```

Море:

```text
+ флотское движение
+ рыболовство
+ морская торговля
+ десанты на соседнюю сушу
```

Озеро:

```text
+ рыба
+ локальный транспорт
+ вода для поселений
- нет морской торговли, если нет связи с рекой/каналом
```

## 4. Рельеф клетки

Рельеф — это форма земли. Он не равен покрову и не равен хозяйству.

Типы рельефа:

```text
flat_plain          // плоская равнина
rolling_plain       // волнистая равнина
lowland             // низина
hills               // холмы
highlands           // возвышенность
foothills           // предгорья
mountains           // горы
high_mountains      // высокие горы
valley              // долина
pass                // перевал, лучше как feature
```

### 4.1 Равнина

Смысл: хороша для пашни, городов, дорог, армейского движения.

```text
agriculture_potential: +25
settlement_potential: +20
movement_cost: -20
road_cost: -20
building_cost: -10
building_time: -10
defense_value: -5
combat_width: +20
large_city_capacity: +15
```

Равнины — база больших зерновых регионов, крупных городов, дорог и армейских манёвров.

### 4.2 Волнистая равнина

```text
agriculture_potential: +15
pasture_potential: +10
movement_cost: -5
road_cost: -5
building_cost: 0
defense_value: +5
```

Универсальный тип. Подходит для многих европейских регионов.

### 4.3 Низина

```text
agriculture_potential: +10
water_access: +10
settlement_potential: +5
flood_risk: +15
health_risk: +10
road_cost: +5
building_cost: +5
```

Низина может быть хорошей, если сухая и плодородная. Если болотистая — резко хуже.

### 4.4 Холмы

```text
pasture_potential: +20
vineyard_potential: +15 если климат тёплый
olive_potential: +10 если климат средиземноморский
mining_potential: +10
defense_value: +20
movement_cost: +20
road_cost: +25
building_cost: +10-20
building_time: +10-20
agriculture_potential: -10
settlement_potential: -5
combat_width: -10
```

Холмы дают оборону, пастбища, руды, виноградники и оливки при подходящем климате. Но хуже для больших зерновых полей и дорог.

### 4.5 Предгорья

```text
pasture_potential: +20
forest_potential: +10
mining_potential: +20
defense_value: +25
movement_cost: +30
road_cost: +35
building_cost: +25
building_time: +25
agriculture_potential: -20
settlement_potential: -10
```

Предгорья — переход между холмами и горами. Хороши для пастбищ, леса, руды, крепостей.

### 4.6 Горы

```text
mining_potential: +35
defense_value: +40
pasture_potential: +10
forest_potential: +10 если есть лес
movement_cost: +60
road_cost: +80-120
building_cost: +40-80
building_time: +40-80
agriculture_potential: -40
settlement_potential: -35
population_capacity: -30
combat_width: -35
winter_attrition: +15
```

Горы не должны быть обычным местом развития. Это барьеры, рудники, перевалы, крепости, монастыри, пастбища.

### 4.7 Высокие горы

```text
defense_value: +60
mining_potential: +20
movement_cost: +100
road_cost: +150
building_cost: +100
building_time: +100
agriculture_potential: -80
settlement_potential: -70
population_capacity: -70
winter_attrition: +30
combat_width: -50
```

Высокие горы лучше использовать как почти непроходимые зоны, кроме перевалов и редких поселений.

### 4.8 Долина

```text
agriculture_potential: +20
water_access: +20
settlement_potential: +20
trade_access: +10
movement_cost: -10
flood_risk: +10
defense_value: 0/+5
```

Долины важны для поселений, дорог и торговли.

## 5. Природный покров

Природный покров — это то, чем земля покрыта без участия человека.

Нельзя включать сюда:

```text
пашня
виноградники
оливковые рощи
городская зона
плантации
дороги
ирригационные поля
```

Это всё человеческое освоение.

### Типы природного покрова

```text
grassland              // травянистая растительность / луга
dry_grassland          // сухие травы
scrubland              // кустарник
maquis                 // средиземноморский кустарник
broadleaf_forest       // широколиственный лес
conifer_forest         // хвойный лес
mixed_forest           // смешанный лес
dense_forest           // густой лес
wetland_vegetation     // болотная растительность

tundra                 // тундра
rocky_ground           // каменистая поверхность
bare_rock              // голые скалы
```


### 5.5 Маквис / средиземноморский кустарник

## 10. Природный ресурс: что это значит

Фраза “ресурс не всегда сразу даёт товар” означает следующее:

```text
Ресурс на клетке может быть не готовым товаром,
а причиной для определённого освоения.
```

### 10.1 Поверхностный ресурс

Можно использовать слабо даже без развитого освоения.

Примеры:

```text
рыба
лес
дикое зверьё
пастбищный потенциал
```

Пример рыбы:

```text
Ресурс: рыба
Без рыбацких пристаней: 1-2 рыбы
С рыбацкими пристанями: 6-10 рыбы
С солью и складами в городе: рыба -> солёная рыба
```

### 10.2 Добываемый ресурс

Без специального освоения почти ничего не даёт.

Примеры:

```text
железная руда
медь
серебро
золото
соль в залежах
мрамор
камень
```

Пример железа:

```text
Ресурс: железная руда
Без рудного промысла: 0 железной руды
Рудный промысел I: 5 руды
Рудный промысел II: 10 руды
Городская плавильня: руда -> железо
```

То есть железная руда на клетке — это не “готовое железо”, а возможность открыть рудный промысел.

### 10.3 Аграрный потенциал

Это вообще не товар, а условие для освоения.

Примеры:

```text
плодородная почва
речная пойма
каменистые сухие склоны
мягкий средиземноморский климат
```

Они сами не производят товар. Они говорят:

```text
здесь хорошо подойдёт пашня / виноградники / оливковые рощи / сады / ирригация
```

Пример:

```text
Каменистые сухие холмы + средиземноморский климат
= высокий потенциал оливковых рощ и виноградников
```

Но пока игрок не выбрал освоение “оливковые рощи”, оливок нет.

## 11. Освоение клетки: правильный термин

Освоение клетки — это **не здание**. Это форма использования территории.

Правильные термины:

```text
Освоение клетки
Тип освоения
Форма освоения земли
Земельное освоение
Промысловое освоение
Инфраструктурное освоение
```

Не надо писать:

```text
Построить пастбище
Построить пашню
Построить виноградники
```

Лучше:

```text
Организовать пастбища
Распахать землю
Заложить виноградники
Заложить оливковые рощи
Открыть лесной промысел
Открыть рудный промысел
Проложить дорогу
```

### Категории освоения

#### Земельное освоение

```text
none
sparse_settlement
villages
farmland
dry_farmland
irrigated_fields
rice_fields
pasture
orchards
vineyards
olive_groves
```

#### Промысловое освоение

```text
logging
managed_ship_timber_forest
mining_district
quarry
saltworks
fishing_harbor
hunting_grounds
```

#### Поселенческое освоение

```text
none
hamlets
villages
dense_villages
urban_outskirts
```

#### Инфраструктурное освоение

```text
dirt_road
main_road
bridge
canal
irrigation_channels
mountain_pass_road
lighthouse
```

Для MVP можно хранить один основной `development_type`, а дороги/ирригацию хранить отдельными флагами.

## 12. Основные типы освоения и эффекты

### 12.1 Нет освоения

```text
output: 0 или минимум
maintenance: 0
nature_preserved: true
wild_resource_possible: true
```

### 12.2 Редкое поселение

```text
population_capacity: small
local_control: +5
output: very low
enables_future_development: true
```

### 12.3 Деревни

```text
population_capacity: medium
labor_pool: +local
tax_base: small
development_speed_nearby: +5
road_need: medium
```

### 12.4 Пашня

Пашня — это обработанная сельскохозяйственная земля, распаханная людьми. Это не природный покров.

```text
requires: suitable soil, not high mountains, not swamp unless drained
output: grain/vegetables depending climate
labor_need: medium
food_supply: high
drought_sensitivity: medium
```

### 12.5 Сухая пашня

```text
requires: dry/normal climate
output: barley/rye/millet depending region
food_supply: medium
drought_sensitivity: lower than normal farmland
yield: lower but stable
```

### 12.6 Ирригационные поля

```text
requires: river/water_access
construction_cost: high
maintenance: high
output: high food
risk: salinization, canal_damage
```

### 12.7 Рисовые поля

```text
requires: warm climate, high water, flat/lowland
labor_need: high
food_output: very high
health_risk: +5
```

### 12.8 Пастбища

```text
requires: grassland/steppe/hills suitable enough
output: meat, milk, wool, hides depending animals
labor_need: low/medium
food_output: medium через мясо и молочные продукты
army_supply: livestock
```

Мясо — это еда. Лучше писать:

```text
Пастбища дают продовольствие через мясо и молочные продукты,
плюс сырьё: шерсть, кожа/шкуры.
```

### 12.9 Виноградники

```text
requires: warm climate, slopes/hills/dry well-drained soil
setup_time: long
maturity: important
output: grapes
city_processing: winery -> wine
trade_value: medium/high
food_value: low
```

Виноградники — не природный покров. Это освоение.

### 12.10 Оливковые рощи

```text
requires: mediterranean/warm dry climate, mild winter
setup_time: very long
maturity: very important
output: olives
city_processing: oil_press -> olive_oil
trade_value: high
food_value: medium
```

Оливки более требовательны к мягкой зиме, чем виноград.

### 12.11 Сады

```text
requires: water, mild/warm climate
output: fruits/nuts
food_variety: +10
trade_value: medium
labor_need: medium
```

### 12.12 Лесозаготовка

```text
requires: forest
output: timber
development_cost: medium
depletion_risk: if overused
clearing_effect: may transform cover over time
```

### 12.13 Управляемый корабельный лес

```text
requires: suitable forest + coast/river access ideally
setup_time: long
output: ship_timber
shipbuilding_bonus: high
private_use_restricted: often
depletion_risk: high if overused
```

### 12.14 Рудный промысел

Лучше не называть это просто “шахта” на уровне клетки. Шахта — это объект внутри промысла. Освоение клетки — **рудный промысел / рудничный округ**.

```text
requires: mineral resource
output: ore
labor_need: high
health_risk: +10
wealth: high
revolt_risk: if harsh labor
requires_road: strongly recommended
```

### 12.15 Каменоломня

```text
requires: stone/marble/rock
output: stone/marble
construction_bonus_city: yes
labor_need: medium/high
road_need: high
```

### 12.16 Сольный промысел

```text
requires: salt resource, coast/lagoon/salt deposit
output: salt
enables_preservation: fish/meat
trade_value: high
```

### 12.17 Рыбацкие пристани / рыбацкое освоение

```text
requires: coastal/river/lake fish access
output: fish
naval_skill_growth: small
labor_need: medium
storm_risk: depends water
```

### 12.18 Дорога / тракт

Дорога — это инфраструктура, а не основное освоение земли. Лучше хранить отдельным слоем.

```text
movement_cost: -20
trade_access: +10
local_control: +5
maintenance: small
```

### 12.19 Военная застава

Это спорный тип: может быть отдельным объектом/инфраструктурой.

```text
control: +15
defense_value: +10
anti_bandit: +10
maintenance: medium
population_capacity: low
```

### 12.20 Городская периферия

Это человеческое освоение, но уже связанное с ростом города.

```text
requires: city growth
population_capacity: high
food_output: negative if replacing farmland
craft_support: +10
trade_access: +10
health_risk: + if overcrowded
```

## 13. Пригодность освоения

Для каждого освоения клетка имеет пригодность.

Лучше не делать “шанс успеха 35%”. Это неприятный рандом.

Лучше:

```text
Пригодность виноградников: 42/100
```

И эффекты:

```text
Стоимость: +40%
Время: +50%
Урожайность: -40%
Риск неурожая: +25%
Содержание: +15%
```

### Шкала пригодности

```text
0-10: невозможно
10-25: почти бессмысленно
25-45: плохо
45-65: нормально
65-85: хорошо
85-100: идеально
```

### Эффекты пригодности

```text
85-100:
  cost: -10%
  time: -10%
  yield: +25%
  risk: -20%

65-85:
  cost: 0
  time: 0
  yield: +10%

45-65:
  cost: +15%
  time: +15%
  yield: 0/-10%

25-45:
  cost: +40%
  time: +50%
  yield: -40%
  risk: +25%

10-25:
  cost: +100%
  time: +100%
  yield: -70%
  risk: +50%

0-10:
  unavailable
```

### Пример пригодности виноградников

```text
base = 0
+ средиземноморский климат: +35
+ холмы: +20
+ каменистая почва: +10
+ сухая/нормальная влажность: +10
+ маквис/сухие травы: +10
- холодный климат: -50
- болото: -80
- высокая гора: -50
```

### Пример пригодности оливок

```text
base = 0
+ средиземноморский климат: +40
+ мягкая зима: +25
+ сухая влажность: +10
+ каменистая почва: +10
+ холмы: +10
- морозные зимы: -35
- влажный океанический климат: -20
- болото: -50
- высокие горы: -30
```

## 14. Уровень освоения

Освоение не должно быть бинарным. Лучше иметь уровень:

```text
development_level: 0-5
```

Пример виноградников:

```text
0 — нет виноградников
1 — малые виноградники
2 — деревенские виноградники
3 — развитые виноградники
4 — террасные/качественные виноградники
5 — знаменитые винные земли
```

Эффекты:

```text
level 1: 30% базового выхода
level 2: 55%
level 3: 80%
level 4: 100%
level 5: 120% + качество
```

Уровень повышается через инвестиции, труд, время, инфраструктуру и традиции.

## 15. Зрелость освоения

Зрелость особенно важна для:

```text
виноградников
оливковых рощ
садов
корабельного леса
ирригационных систем
```

```text
maturity: 0-100
```

### Виноградники

```text
0-20: посадка лоз
20-50: слабый урожай
50-80: нормальный урожай
80-100: полный урожай
```

Игровое упрощение:

```text
год 1: 0-10% урожая
год 2: 10-20%
год 3: 30-40%
год 5: 70%
год 8: 100%
```

### Оливковые рощи

Оливки созревают дольше:

```text
год 1-3: почти нет выхода
год 4-6: слабый выход
год 8-10: нормальный выход
год 10+: полный выход
```

## 16. Повреждение клетки

```text
damage: 0-100
```

Причины:

```text
война
разорение
пожар
засуха
наводнение
эпидемия скота
пиратский рейд
восстание
саботаж
```

Эффекты:

```text
output: -damage%
labor_need: +damage/2
migration_attraction: -
crime/banditry: +
tax: -
repair_cost: +
```

Пример:

```text
Виноградники damage 40:
урожай -40%
зрелость может упасть
нужен ремонт 2 года
```

## 17. Истощение и деградация

Некоторые освоения могут портить клетку.

### 17.1 Перевыпас

```text
pasture_overuse:
  soil_quality decreases slowly
  drought_risk increases
  pasture_yield decreases
```

### 17.2 Вырубка леса

```text
forest_depletion:
  timber_output decreases
  cover changes dense_forest -> forest -> scrubland/grassland
  erosion_risk increases
```

### 17.3 Ирригация

```text
salinization_risk:
  soil_quality decreases
  requires canal_maintenance
  especially dangerous in dry/saline regions
```

### 17.4 Рудный промысел

```text
resource_depletion:
  ore_output slowly decreases if deposit is finite
  mine_depth increases cost and danger
  health risk grows
```

## 18. Инфраструктура клетки

Инфраструктура отличается от освоения. Она не всегда производит сырьё, но делает клетку доступнее и эффективнее.

Типы:

```text
road_level: 0-3
bridge: true/false
irrigation: 0-3
canal: true/false
local_storage: true/false
lighthouse: true/false
fortified_point: true/false
```

### 18.1 Дороги

```text
movement_cost: -
trade_access: +
local_control: +
army_supply: +
market_access: +
```

Уровни:

```text
0 — нет дороги
1 — тропа / просёлок
2 — тракт
3 — мощёная/главная дорога
```

### 18.2 Мост

```text
river_crossing_penalty: -
trade_access: +
strategic_value: +
defense/raiding importance: +
```

### 18.3 Ирригация

```text
farmland_yield: +
drought_resistance: +
maintenance_cost: +
salinization_risk: + in dry/saline soils
```

### 18.4 Маяк / навигационная точка

```text
coastal_trade_risk: -
shipwreck_risk: -
port_effectiveness: +
strategic_value: + small
```

## 19. Строительство зданий и зависимость от клетки

Здания делятся на:

```text
1. Городские здания — строятся в городе.
2. Клеточные объекты/инфраструктура — дороги, мосты, каналы, заставы.
3. Освоение земли — не здания, а форма использования территории.
```

### 19.1 Что влияет на стоимость и время строительства

```text
relief_type
natural_cover
soil_type
climate_type
moisture_type
features
local_resources
infrastructure
labor_available
city_skill
security/damage
```

### 19.2 Формула строительства

```text
final_cost = base_cost
  × relief_modifier
  × cover_modifier
  × soil_modifier
  × climate_modifier
  × infrastructure_modifier
  × resource_modifier
  × damage_modifier
```

```text
final_time = base_time
  × relief_time_modifier
  × climate_time_modifier
  × labor_modifier
  × road_access_modifier
  × damage_modifier
```

### 19.3 Рельеф и строительство


Важно: горы не делают крепость дешёвой абсолютно. Они делают крепость эффективной. Строить всё равно тяжело.


#### Песчаный берег

```text
enemy_landing_difficulty: -20
coastal_defense: -5
```

### 19.4 Покров и строительство

```text
fields_setup_time: +20%
```

```text
defense_against_large_fleet: +10
```

#### Ледяные воды

```text

fishing_seasonality: high
```

#### Сильные течения

```text
movement_direction_bonus_or_penalty
```

## 21. Strategic value: что это и где используется

`strategic_value` не должен быть видимым бонусом игроку вида “+50”. Это служебный показатель.

Он отвечает:

```text
Насколько эта клетка важна для войны, логистики, торговли, AI и дипломатии.
```

### Где используется

#### 21.1 AI выбирает цели войны

Гибралтар, Босфор, перевалы, крупные порты получают высокий strategic_value. AI понимает, что их стоит захватывать и удерживать.

#### 21.2 AI строит крепости

Высокий strategic_value у:

```text
перевала
пролива
устья реки
пограничного порта
моста
ключевой дороги
```

AI может решить:

```text
построить крепость
поставить гарнизон
держать армию рядом
укрепить порт
```

#### 21.3 AI защищает важные места

Порт с верфью и гаванью будет защищаться сильнее, чем обычная сельская клетка.

#### 21.4 Военные маршруты

Pathfinding может учитывать не только кратчайший путь, но и важные точки:

```text
захватить перевал
взять мост
обойти крепость
занять порт снабжения
```

#### 21.5 Мирные договоры

Клетка с высоким strategic_value стоит дороже в переговорах.

```text
обычная сельская клетка: ценность 10
плодородная клетка: 20
город: 50
порт: 70
пролив: 120+
```

#### 21.6 События и советы

Совет может сообщать:

```text
“Перевал через горы слабо защищён.”
“Этот пролив контролирует торговлю.”
“Порт стал ключевым для атлантических маршрутов.”
```

#### 21.7 Торговля и логистика

Если враг контролирует стратегическую клетку:

```text
маршруты дороже
снабжение хуже
армии идут в обход
торговля падает
```

### Как показывать игроку

Не показывать:

```text
strategic_value +50
```

Показывать:

```text
Стратегическое значение: высокое
Причины:
- контролирует пролив
- рядом торговый путь
- удобная гавань
- ключевой проход через горы
```

## 22. Разные типы ценности клетки

Лучше не смешивать всё в один показатель.

```text

military_value     // оборона, снабжение, крепости
```

### Плодородная равнина


### Горный перевал

```text

strategic_value: высокий
```

### Пролив

```text

```

### Естественная гавань

```text
economic_value: средний

strategic_value: высокий
```

## 24. Городская переработка

Клетка не производит сложный товар, если для этого нужен город.

```text
Клетка: виноградники -> виноград
Город: винодельня -> вино
```

```text
Клетка: оливковые рощи -> оливки
Город: маслобойня -> оливковое масло
```

```text
Клетка: пашня -> зерно
Город: мельница/пекарни/склады -> мука/хлебное снабжение
```

```text
Клетка: рыбацкие пристани -> рыба
Город: соль + склады -> солёная рыба
```

```text
Клетка: рудный промысел -> железная руда
Город: плавильня -> железо
Город: кузница -> инструменты/оружие
```

## 27. Как клетка влияет на навыки населения

Навыки лучше хранить в городе/провинции, а не в клетке.

Клетка и её освоение дают прирост навыков:

```text

рудный промысел -> mining skill
лесозаготовка -> forestry/carpentry skill
корабельный лес -> shipbuilding support if there is shipyard
```

Пример:

```text

```

## 29. Итоговая формула выхода клетки

Примерная формула:

```text
output = base_output
  × suitability_factor
  × development_level_factor
  × maturity_factor
  × labor_factor
  × infrastructure_factor
  × weather_factor
  × damage_factor
```

Пример виноградников:

```text
base_output = 10 винограда
suitability = 0.85
level = 1.0
maturity = 0.75
labor = 0.9
infrastructure = 1.0
weather = 1.0
damage = 0.8

итог = 10 × 0.85 × 1.0 × 0.75 × 0.9 × 1.0 × 1.0 × 0.8
итог = 4.59 винограда
```

## 31. Как игрок должен выбирать освоение

Игрок кликает по клетке и видит:

```text
Клетка: прибрежные влажные холмы

Природа:
- холмы
- луга и редколесье
- океанический влажный климат
- обычная почва
- побережье рядом

Рекомендуемые освоения:
1. Пастбища — пригодность 78
2. Лесной промысел — пригодность 62
3. Рыбацкая поддержка — пригодность 55

Можно, но невыгодно:
4. Пашня — пригодность 48
5. Виноградники — пригодность 42

Недоступно:
6. Оливковые рощи — пригодность 15, слишком влажно/холодно
7. Рисовые поля — нет условий воды/климата
8. Рудный промысел — нет руды
```

Игрок не должен видеть 30 равнозначных вариантов. Надо разделять:

```text
Рекомендуется
Можно
Плохо
Недоступно
```

## 33. Что пересчитывать каждый ход, а что кэшировать

Не надо каждый ход пересчитывать пригодность всех освоений для всех клеток.

### Считать при генерации/редко

```text
base_suitability for farmland
base_suitability for pasture
base_suitability for vineyards
base_suitability for olive_groves
base_suitability for logging
base_suitability for mining
base_suitability for port
```

### Считать каждый ход/год только активное

```text
output current development
maturity growth
damage recovery
labor availability
weather effects
maintenance
```

Для 20 000 клеток это нормально.

## 34. Производительность

При 20 000 клеток система клеток не должна быть тяжёлой.

Примерная память:

```text
20 000 клеток × 64-128 байт = 1.3-2.5 МБ
если жирно по 512 байт = около 10 МБ
```

Основная опасность не клетки, а:

```text
AI
pathfinding
торговые маршруты
ежедневные/ежемесячные пересчёты всего мира
UI, если он пересчитывает мир при открытии окна
```

Правильный принцип:

```text
Клетки хранят лёгкие данные.
Потенциалы кэшируются.
Каждый ход считается только активное освоение и изменившиеся состояния.
```

## 36. Главные правила системы

1. Клетка не должна быть одним типом.
2. Пашня, виноградники, оливковые рощи — не природа, а освоение.
3. Мясо — это еда, но лучше хранить как отдельный пищевой товар.
4. Ресурс не всегда даёт товар сразу: руда требует рудного промысла, виноград требует виноградников, железо требует плавильни.
5. Освоение клетки — не здание, а форма использования территории.
6. Городские здания отвечают за переработку и усиление сырья.
7. Рельеф влияет не только на бой, но и на строительство, дороги, население, добычу и освоение.
8. Strategic value — служебный показатель для AI, войны, дипломатии, логистики и событий.
9. Игроку надо показывать смысл, а не голые “+50 strategic value”.
10. Система должна быть глубокой, но кэшированной и лёгкой для производительности.

## 37. Финальная модель

```text
Природа клетки
↓
потенциалы освоения
↓
игрок выбирает освоение
↓
освоение развивается и созревает
↓
клетка даёт сырьё/еду/рабочие места/стратегический эффект
↓
город перерабатывает сырьё зданиями
↓
товары идут в население, торговлю, армию и экспорт
```

Пример:

```text
Холмы + маквис + каменистая почва + средиземноморский климат
↓
высокая пригодность оливковых рощ и виноградников
↓
игрок выбирает оливковые рощи
↓
10 лет до полной зрелости
↓
клетка производит оливки
↓
городская маслобойня делает оливковое масло
↓
масло идёт в еду, торговлю и экспорт
```

Это исторично, понятно и даёт много игровых решений без превращения карты в набор случайных бонусов.
