# Fantasy Admin-2: рабочий pipeline

Этот документ фиксирует исполнимую версию процесса из `ADMIN2_MODDING_PIPELINE.md`.

## Один запуск

```powershell
python scripts/tools/admin2_pipeline.py --all --build
```

Команда выполняет четыре стадии:

1. Генерирует Admin-2 для доступных Admin-1 по таблице региональных профилей.
2. Валидирует точное покрытие, пересечения, связность, анклавоподобные зоны, баланс площади, компактность, вытянутость, соседство и характер границ.
3. Присваивает оценку `0–100` и статус: `AUTO_APPROVED` (≥90), `ACCEPTED` (75–89.99) или `NEEDS_REVIEW` (<75 либо ошибка геометрии).
4. Экспортирует игровое JSON-представление, GeoJSON и очередь ручной проверки.

## Артефакты

- `assets/cells_iberia_regional_political_claims.json` — игровая геометрия Admin-2, загружаемая текущим слоем Godot.
- `reports/admin2_pipeline_iberia.json` — полный отчёт качества.
- `assets/cell_topology/admin2_review_queue.json` — упорядоченная очередь проблемных Admin-1 для редактора.
- `build_artifacts/fantasy_admin2_iberia.geojson` — переносимый векторный обменный формат для QGIS/GIS-проверки.

Для рабочего GeoPackage после установки зависимостей используйте:

```powershell
pip install -r requirements_land_cells_v2.txt
python scripts/tools/admin2_pipeline.py --all --geopackage
```

## Ручной цикл

1. В Godot нажать `F`, чтобы включить слой `Political Claims`. `R` остаётся сбросом камеры.
2. Открыть первый `province_id` из очереди и скорректировать границы доступными инструментами топологии.
3. Зафиксировать удачные границы/зоны в `assets/cells_layer4_approved_partitions.json`.
4. Повторить команду. Одобренные разбиения генератор сохраняет и не перезаписывает.

## Формат хранения

JSON остаётся рантайм-форматом Godot. GeoJSON — форматом обмена. GeoPackage выпускается опционально командой pipeline; это намеренно не является обязательной зависимостью игрового рантайма.

## Гарантии

Валидатор не исправляет ошибки молча. Любая потеря покрытия, наложение либо несвязная клетка понижает статус до `NEEDS_REVIEW`. Внешняя граница исходного Admin-1 считается неизменяемой.
