# Global Strategy Prototype (v0.2)

Прототип глобальной стратегии на **Godot 4**.
**Тайловая карта мира** с глубоким зумом (весь мир → до острова/региона) и
**переключаемыми слоями** (спутник / политический / экономический / религиозный /
моря / континенты / суша-море / реки / провинции / тестовые игровые клетки).

Пока без экономики, юнитов, городов, стран и ИИ — только карта, слои, камера и
первая тестовая проводка игровых данных клетки (без UI). Подробное текущее
состояние — см. [done.md](done.md), актуальные задачи — [TODO.md](TODO.md),
правила и согласованные решения по архитектуре/стеку — [CLAUDE.md](CLAUDE.md).

## Ключевая идея: тайлы, а не одна картинка

Гигантскую карту нельзя держать одним `Sprite2D` — не хватит ни лимита размера
текстуры (~16384 px), ни памяти. Поэтому используется **тайловая пирамида**
(как Google/Yandex Maps): мир нарезан на квадраты по уровням зума, в каждый
момент грузятся **только видимые тайлы** нужного уровня детализации (LOD).
Память остаётся маленькой при любом размере мира.

Базовый слой сейчас — реальные онлайн-тайлы Земли (ESRI World Physical Map),
с кэшем на диске и полностью офлайновым bundle-кэшем в `assets/tiles_bundle/`
(см. done.md). Остальные слои — либо реальные геоданные (моря, реки,
континенты, суша/море, провинции), либо пока процедурные заглушки
(политический/экономический/религиозный оверлеи).

## Управление

| Действие | Клавиши / мышь |
|----------|----------------|
| Двигать камеру | `W A S D` или стрелки |
| Зум к курсору | Колесо мыши |
| Тащить карту | Зажать ПКМ или СКМ |
| Вернуть в центр | `R` |
| Выход | `Esc` |
| Разметка карты (отладка) | `M` вкл/выкл, `Tab` режим, ЛКМ метка, `Z` отмена, `Delete` очистить |
| Слои вкл/выкл | `1` спутник, `2` полит., `3` эконом., `4` религ., `6` моря, `0` континенты, `-` суша/море, `=` реки, `8` провинции (реальные), `C` тестовые игровые клетки (Ла-Корунья), `J` клетки Иберии V9 Collision Blocking |

Внизу экрана — статус: активные слои, текущий LOD, зум, число загруженных тайлов.

## Как запустить

1. Установить **Godot 4.7+** (Standard, с GDScript): https://godotengine.org/download
2. Godot → **Import** → выбрать `Map/project.godot`.
3. **F5**. Сцена `Main.tscn` стартует автоматически.

Интернет не нужен для полностью загруженного bundle-кэша (см. done.md); без
него часть слоёв догружает тайлы онлайн при первом запуске.

## Как устроены слои

Все слои описаны в `TileMapViewer.gd` (`_ready()`) как единый список: у
каждого элемента — имя, провайдер (`*TileProvider.gd`/`BakedTileProvider`) и
видимость. Добавить новый слой = добавить один элемент с провайдером и
повесить на клавишу (см. `_unhandled_input` в том же файле).

Полное и актуальное описание того, что сделано в каждом слое — в
[done.md](done.md); список открытых задач и решений по ним — в
[TODO.md](TODO.md).
